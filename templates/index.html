Azure AI Vision Web App

This app use the Azure services for image analysis, image classification, object detection, face analysis, OCR.

1. Image Summary

Get a simple summary with caption, tags, objects, and people from your image.

Upload an image to see a friendly scene summary.

The analyzed image preview will appear here.

2. Image Classification

Runs your custom classification model from the fruit lab.

The best prediction and confidence scores will appear here.

The classified image preview will appear here.

3. Find Objects in Image

Shows a summary of the objects found and highlights them with red boxes on the output image.

The detected object summary will appear here.

The output image with detected objects will appear here.

4. Face Analysis

Uses the Azure Face endpoint and draws face boxes directly on the uploaded image.

Upload an image to see the annotated face detection result.

The detected face preview will appear here.

5. OCR / Read Text

Reads printed or handwritten text with Azure AI Vision.

Recognized text will appear here in a clearer format.

The text regions will be highlighted on the image here.
